3. Original game files
   This release includes data files of Mine Bombers 3.11, which remain
   the property of Skitso Productions.
   The freeware release of the original game carries this statement in
   its FILE_ID.DIZ (dated 27 December 2001):
     "Mine Bombers 3.11 Registered version
      FREEWARE VERSION! MAY BE DISTRIBUTED"
   The game's own history file (HISTORIA.TXT) records the same release:
     "31.12.2001 Rekisteroity versio julkaistu freewarena"
     (the registered version released as freeware).
   The data files are included only so that the game can be played as it
   was. Nothing else from the original release is claimed by this project.
